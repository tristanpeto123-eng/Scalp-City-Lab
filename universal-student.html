RUN FROM YOUR IPHONE

Start a training generation

  1. Choose the target market and source model above.
  2. Tap Train via GitHub, then sign in to GitHub if prompted.
  3. Open Run workflow, select main, and enter the same target/source. Leave episodes at 3.
  4. Tap Run workflow. When the run finishes, return here and press Reload progress.

The browser page cannot securely start an authenticated GitHub Actions run without a sign-in backend. It opens GitHub's own authenticated workflow controls instead; no personal access token is requested or stored here.
