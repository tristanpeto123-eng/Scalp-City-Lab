4 / Continuous SL learning loop

Load chart data → virtual next-open trade → close and score → teach good/bad memory → retrain → check the next completed 5m bar. Decisions are frozen before future outcomes are known. Each completed candle is processed once.

Simulation only. This loop has no broker orders. It runs only while this browser page remains open and awake. Closing Safari, iOS suspending the page, losing your network connection or API credits stops or delays it. A new provider request consumes API credits; no key is persisted. Never interpret simulated results as broker profit.

Basic 8 credit saver: one SL loop time-series request per market symbol every 60 minutes, not every 5 minutes. Twelve Data charges 1 credit per symbol per request regardless of returned bars (up to 5,000). Initial training loads 5,000 candles; routine batches cover 150 candles (~12.5 trading hours). Estimate: 24 credits per day per student, 72 credits per day for three students, excluding manual requests. Twelve Data Basic 8 quota: 800/day, 8/min. Gold requires separate provider entitlement.
